Support

Updated: 19 September 2026

How to reach us

Email Northwick.apps@gmail.com. This is the support channel for all Northwick apps, including Review Due for Confluence Cloud.

Response time

We reply to every request within one business day (Sunday to Thursday, Israel time). Most questions are answered the same day. Bugs that block the app for all users on a site are prioritised over feature requests.

What to include

Including the following helps us solve the issue in one round trip:

  • The app name (for example, Review Due) and, if you know it, the app version shown in Manage apps.
  • Your Atlassian site URL (for example, yourcompany.atlassian.net). Never send passwords or API tokens.
  • What you did, what you expected, and what happened instead.
  • The page or space where it happened, if the issue concerns a specific page.
  • A screenshot, if the issue is visual. Please blur anything confidential first.
  • The approximate time it happened, including your time zone.

Known issues and status

Known issues, workarounds and fix status are tracked publicly in GitHub Issues for this site. Check there before reporting; if your issue is already listed, add a comment or a reaction and we will notify you when it is resolved. You do not need a GitHub account to read the list.

Feature requests

We welcome ideas. Email them or open a GitHub issue with the label enhancement. We cannot promise to build every request, but we read them all.

Privacy and data requests

For questions about stored data or to request deletion, see the Privacy Policy and email us from an address associated with your Atlassian site.
